This repository contains the open-source software artifacts, microcontroller firmware, and analytical regression suites supporting the empirical engineering education research article submitted to *Computer Applications in Engineering Education* (CAEE, Wiley).

---

## 🔒 Data Availability Statement
> **Data Privacy Notice:** In compliance with student academic privacy regulations and institutional ethics guidelines (**IRB Protocol No. IRB-2023-EE-042**), the de-identified teaching evaluation datasets generated during the three-year quasi-experimental study are **not publicly accessible** in this open repository. Academic researchers may request access to the de-identified evaluation records for replication purposes by contacting the corresponding author via institutional email.
