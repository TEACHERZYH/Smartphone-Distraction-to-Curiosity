## 二、 核心固件模块技术特性与实现细节

### 1. 可见光通信发端固件 (`vlc_transmitter`)
*   **硬件外设与调制引擎**：
    *   调用 ESP32 底层 `ledcSetup` 与 `ledcWrite` 硬件定时器外设，在 GPIO 4 上产生高精度的方波；
    *   **2FSK 调制映射**：逻辑比特“0”对应 $250\text{ Hz}$，逻辑比特“1”对应 $500\text{ Hz}$，占空比严格保持对称的 $50\%$（默认寄存器值 `128/255`）；
    *   **符号时钟控制**：单比特符号持续时间固定为 $250\text{ ms}$。在主流智能手机 $30\text{ fps}$ 录像流中，单比特跨越 $7 \sim 8$ 帧画面，确保手机端具备充裕的多帧累积观测与鲁棒判决容限。
*   **非阻塞有限状态机（FSM）协议栈**：
    *   状态机由硬件时钟驱动，严格按照 **最高有效位（MSB）优先** 逐位推流：
        1.  `TX_STATE_PREAMBLE`：推流 8 位交替前导码 `0b10101010` (`0xAA`)；
        2.  `TX_STATE_DELIMITER`：推流 8 位帧起始定界符 `0b11100010` (`0xE2`)；
        3.  `TX_STATE_LENGTH`：推流 8 位载荷字节长度（默认发送“OK”为 `0x02`）；
        4.  `TX_STATE_PAYLOAD`：依次推流各 ASCII 字符的二进制编码（'O': `0x4F`, 'K': `0x4B`）；
        5.  `TX_STATE_GUARD_INTERVAL`：帧尾强制熄灭 LED 并维持 $1000\text{ ms}$ 的暗光保护间隔，为手机端算法提供清晰的帧切片定界边界。
*   **双重交互控制与单变量挑战支持**：
    *   **物理按键切换（GPIO 0 BOOT 键）**：集成硬件防抖逻辑，短按循环切换 5 种实验模式：
        *   *Mode 1*：40-bit 2FSK 协议帧循环推流（教学默认，发送“OK”）；
        *   *Mode 2*：恒定 $250\text{ Hz}$ 纯方波输出（供学生标定“0”空间条纹周期 $P_0$）；
        *   *Mode 3*：恒定 $500\text{ Hz}$ 纯方波输出（供学生标定“1”空间条纹周期 $P_1$）；
        *   *Mode 4*：占空比步进挑战模式（自动在 $25\% \to 50\% \to 75\%$ 之间轮转，用于受控单变量探究）；
        *   *Mode 5*：待机模式（LED 完全熄灭）。
    *   **串口命令行（CLI, 115200 bps）**：支持动态更新发送字符（`SEND "HELLO"`）、重设占空比（`DUTY <25|50|75>`）与工作模式查询。

### 2. Wi-Fi CSI 射频发端固件 (`wifi_csi_transmitter`)
*   **确定性射频基线配置**：
    *   配置 ESP32-S3 为 SoftAP 模式，广播专属教学 SSID `EE-Lab-CSI-01`，强制锁定在 $2.4\text{ GHz}$ 专用信道 6（$2437\text{ MHz}$），彻底消除跳频对信道多径的干扰；
    *   强制指定物理层为 $802.11\text{n}$ HT20（$20\text{ MHz}$ 带宽），锁定最大发射功率为 $20\text{ dBm}$（寄存器值 `80`），防止动态功率自适应调整引入伪波动。
*   **高频微秒级硬件定时发包**：
    *   通过 ESP-IDF 底层高精度 `esp_timer` 硬件定时器，以严格 **$100\text{ Hz}$**（每 $10000\ \mu\text{s}$ 一次）触发中断服务例程；
    *   调用底层 `esp_wifi_80211_tx` API 直接向空中广播标准 IEEE 802.11 Action 探测包。
*   **自包含时序凭据**：
    *   每个探测包负载内嵌 32 位单调递增序列号（Sequence Number）与微秒级时间戳，用于接收端精准统计网络丢包率与时延抖动。

### 3. Wi-Fi CSI 射频收端固件 (`wifi_csi_receiver`)
*   **无休眠连续监听**：
    *   配置为 STA 模式，调用 `esp_wifi_set_ps(WIFI_PS_NONE)` 强制关闭 Wi-Fi 芯片的休眠节电机制，确保高速数据流零丢包捕获。
*   **底层 DMA 异常对齐保护**：
    *   在 `wifi_csi_rx_callback` 中检测 `first_word_invalid` 标志；若底层抛出异常标志，驱动自动前移 4 字节偏移，杜绝由于 DMA 接收对齐偏差导致的子载波错位。
*   **52 核心有效子载波幅度解构**：
    *   根据 IEEE 802.11n 规范，HT20 包含 64 个频点。固件通过预计算掩码数组自动剔除直流偏置（DC, 索引 0）、7 个边缘保护频点以及 4 个导频载波（-21, -7, 7, 21），筛选出 52 个核心数据子载波；
    *   对提取出的 52 组复数 $(I_k, Q_k)$ 计算瞬时物理幅度：
        $$a_k(t) = \sqrt{I_k^2(t) + Q_k^2(t)}$$
*   **结构化串口高速推流**：
    *   以 `CSI,Seq_ID,RSSI,NoiseFloor,Amp_0,Amp_1,...,Amp_51` 格式向 PC 实时高速吐送数据流，供 Web 实验平台与 Python 脚本绘制时空瀑布图。

*核心器件：两块 ESP32-S3-DevKitC-1 开发板 (分别烧录 TX 发端与 RX 收端固件)*

## 四、 快速上手步骤

### 1. 快速编译与烧录（推荐 VSCode + PlatformIO）

1.  **打开工程**：
    在 VSCode 中安装 **PlatformIO IDE** 插件，点击 `Open Project`，直接选择本 `microcontroller_firmware_project` 根文件夹。
2.  **切换与编译目标环境**：
    在 VSCode 左下角状态栏点击环境切换图标，根据当前连接的开发板选择对应目标：
    *   烧录可见光发端板：选择 `env:vlc_tx`，点击 **Build (√)** 编译；
    *   烧录 Wi-Fi CSI 发端板：选择 `env:csi_tx`，点击 **Build (√)** 编译；
    *   烧录 Wi-Fi CSI 收端板：选择 `env:csi_rx`，点击 **Build (√)** 编译。
3.  **一键烧录**：
    用数据线连接对应开发板，点击底部状态栏的 **Upload (→)**，固件将自动编译并烧录至微控制器中。

*(注：亦可使用 Arduino IDE 打开各子工程 `src/main.cpp`，开发板型号选择 `ESP32 Dev Module` 或 `ESP32-S3 Dev Module` 进行直接烧录。)*

### 2. 硬件测试与 PC 端辅助工具调试

#### 验证步骤 A：VLC 协议与算法验算
在电脑终端运行配套的协议自校验脚本：
```bash
cd tools
python3 vlc_frame_validator.py
```
*   **预期输出**：
    终端将根据式 $P = 1 / (f \cdot t_r)$ 自动推导 $250\text{ Hz}$（$P_0 = 160.0\text{ 行}$）与 $500\text{ Hz}$（$P_1 = 80.0\text{ 行}$）的理论空间周期，并自动将字符串“OK”编码为 40-bit 二进制数据流进行完整性解码断言，验证通过后提示 `>>> VALIDATION SUCCESS <<<`。

#### 验证步骤 B：VLC 串口交互与工作模式切换
连接 VLC 发端板至电脑，打开串口调试助手（波特率 `115200`，行尾添加 `\n`）：
*   输入 `STATUS`：查看当前模式、频率与占空比；
*   输入 `MODE 2`：强制输出 $250\text{ Hz}$ 纯方波（用于学生进行条纹宽度标定基线测量）；
*   输入 `MODE 3`：强制输出 $500\text{ Hz}$ 纯方波（用于学生进行条纹宽度标定基线测量）；
*   输入 `SEND "HELLO"`：动态修改载荷，微控制器即时重新打包 40-bit 帧并推流。

#### 验证步骤 C：Wi-Fi CSI 射频链路与实时方差监控
将烧录了 `csi_rx` 固件的 ESP32-S3 板插入 PC（假设识别为 `COM3` 或 `/dev/ttyUSB0`）：
```bash
cd tools
# 监听真实硬件串口数据流
python3 serial_csi_logger.py COM3 115200

# 若暂无硬件，可运行离线动态仿真模式进行教学演示
python3 serial_csi_logger.py sim
```
*   **现象观察**：
    当测试区域静止无人时，52 个数据子载波方差稳定在基线以下（输出 `STATIC EMPTY ROOM`）；当有人在收发轴线附近走动时，多径相位剧烈干涉，方差大幅跃升，终端即时高亮告警 `>>> MOTION DETECTED <<<`。
